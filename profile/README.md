## 🏠 가족 중심의 스마트 데이터 플랫폼
HotSpot은 흩어져 있는 **가족 공유 데이터 관리**와 **차단/제어(자녀 보호 포함)** 흐름을 하나로 합친 가족 데이터 통합 관리 플랫폼입니다.

---
</br>

## ⚠️ 해결하려는 문제: 파편화된 가족 데이터 관리

가족 데이터 관리는 **운영**이 어렵습니다.

</br>

### ⚡ 1) 분리된 기능으로 인한 가족 운영의 어려움
- 데이터 공유/배분은 A 서비스에서 하고
- 사용 제한/차단은 B 서비스에서 하고
- 결과 확인(누가 얼마나 썼는지/왜 제한됐는지)은 또 다른 화면에서 확인합니다.

→ 결국 가족 입장에서는 **규칙을 세우고 지키게 만드는 UX**가 아니라, **설정이 흩어진 관리**가 됩니다.

</br>

### 💥 2) 차단에 대한 반발, 공유에 대한 갈등
- 부모: 요금폭탄/과몰입 걱정 → 기준이 필요
- 자녀: 감시/일방 차단 거부감 → 납득 가능한 룰이 필요
- 가족: 형평성(독점) → 배분과 제어가 같이 가야 함

→ 그래서 HotSpot은 **공유(배분)** 와 **제어(정책)** 를 분리하지 않고, **하나의 흐름으로 묶어서** 제공합니다.

## ✅ HotSpot의 핵심 가치: 통합

### 📊 1) 하나의 대시보드에서 가족 데이터 운영을 끝내기
- 가족 전체 잔여량 / 소진 속도 / 리셋까지 D-day
- 구성원별 사용량, 개인 한도, 우선순위
- 앱/카테고리 단위 사용량 인사이트

### ⚙️ 2) 배분(공유)과 정책(제어)을 연결하기
- **배분**: 누구에게 얼마나 줄지(데이터 선물)
- **정책**: 어떤 조건에서 어떻게 제한할지(시간대/앱/우선순위/임계치)
- **알림**: **왜/언제** 제한됐는지 투명하게 설명

  → 결과적으로 공유만 하는 서비스가 아니라 **공유 → 관리 → 피드백(알림/리포트)** 까지 이어지는 통합 흐름을 제공합니다.

### 🛡️ 3) 권한/책임을 명확히 하는 가족 운영 모델
- 가족 대표/보호자/구성원 권한 분리
- 정책 설정 변경 이력(누가/언제/무엇을) 기록
